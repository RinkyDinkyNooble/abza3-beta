# Changelog

## [3.0.2] CLIENT - 2026-11-19

- Needs a new world. Worlds from 3.0.1 aren't supported.
- Fixed the detonator never showing up in loot, and mobs healing to full when their chunk reloads.
- The anvil only puts enchantments on gear they fit, never next to a conflicting one, and equal books stop at the enchantment's max level.
- Lowered the Bomber's explosion damage from 1000 to 12.
- Lost Cities no longer builds stairs between streets.
- Added Scalpel, which replaces JEITweaker, Item Obliterator and Item Obliterator Despawn Fix.
- Removed The Flesh That Hates, Prion Infection and Entomophobia, which 3.0.1 shipped turned off.
- Updated Superb Warfare to 0.8.9.2 and added [SBW] Performance Fix for better FPS around mob crowds.
- Added the ABZA Shader pack. No shader is on by default, and BSL's custom settings are gone.
- The title and loading screens show "Version 3.0.2" without "PRE-ALPHA | 10% Complete".
- Turned off the Distant Horizons memory warnings and the Oculus update message.
- New animated pack icon.
- Removed leftover files 3.0.1 shipped by mistake.

## [3.0.2] SERVER - 2026-11-19

- Needs a new world. Worlds from 3.0.1 aren't supported.
- Building commands (/spawn, /placeBlockEntity, /placeKeypad, /placeKeycardReader, /spawnNPC, /pregen) now need operator permission, so players can't use them to spawn items and mobs.
- Fixed bandit, police and survivor NPCs not spawning in buildings on Linux servers.
- Fixed the detonator never showing up in loot, and mobs healing to full when their chunk reloads.
- The anvil only puts enchantments on gear they fit, never next to a conflicting one, and equal books stop at the enchantment's max level.
- Lowered the Bomber's explosion damage from 1000 to 12.
- Lost Cities no longer builds stairs between streets.
- Added Scalpel, which replaces JEITweaker, Item Obliterator and Item Obliterator Despawn Fix.
- Removed The Flesh That Hates, Prion Infection and Entomophobia.
- Updated Superb Warfare to 0.8.9.2 and added [SBW] Performance Fix.
- The server list shows the pack name and version, with a new server icon.
- Pinned the server starter jar to 0.1.35.
- Removed leftover disabled mods and files.

## [3.0.1] - 2026-07-13

- The last release before this repository. CLIENT/ and SERVER/ in the first commit are the published files.
